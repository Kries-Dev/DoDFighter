## What this is

An OpenLF2 (Little Fighter 2 remake) mod with original fighters. Everything
lives in **one mod**, `mods/darthnox/`, which is loaded with
`--mod mods/darthnox`. The user wants Claude to **do all file operations
itself**: copy files, install, push and relaunch, never give manual steps.

| Where | Path |
|---|---|
| Repo (push to `main`, git identity Kries-Dev) | `github.com/Kries-Dev/DoDFighter`, last clone in the old session's scratchpad |
| Installed game | `C:\Users\Kries\AppData\Local\Programs\OpenLF2\` (mod at `mods\darthnox\`) |
| LF2 installer (headless runs need it) | `C:/Users/Kries/AppData/Roaming/OpenLF2/LF2_v2.0a.exe` |
| Game settings | `%APPDATA%\OpenLF2\config.json` (upscaling set to `linear`; xBRZ made the menu blank) |
| Engine source (read it, don't guess) | `github.com/OpenLF2/OpenLF2`; scripts are also in `...\OpenLF2\scripts\base\` |

**Install:** copy `mods/darthnox` from the repo over the installed one.
**Relaunch:** first `taskkill //IM openlf2.exe //F` (old windows stay open and the user may test a stale build), then
`cmd.exe //c start "" openlf2.exe --mod mods\darthnox` from the game folder.

**Adding a fighter:** add it to `fighters_added`, the `FIGHTERS` base table and
`DEFENCE`, list its assets in `package.manifest`, and give it a generator
script modelled on `mathilde_moves.py`.

## Testing: headless probe mods

Scripted menu input doesn't get past the title screen. Instead:
1. Write `mods/probe/` with the manifest `requires=darthnox@1` and
   `extend=base/ui/title|title.lua`.
2. In it, override `title.create` to build a match with `match.create`
   (slot 0 our fighter, slot 1 Deep, both human) and step it with
   `match.step`.
3. Report through `error()`.
4. Run: `openlf2.exe --headless --installer <exe> --mod mods/darthnox --mod mods/probe --input-trace ",,,,,@400_229!,,,,,"`.

Rules for probes:
- Wait about 220 steps before inputs register.
- Hold keys 2 ticks with 1 gap. Letters: `c` attack, `b` jump, `f` defend,
  `u d l r` directions; `"/c"` means player 2.
- Zero velocities when repositioning fighters.
- Delete the probe afterwards.

A ready-made probe is in `tools/probe_template.lua`: it measures hitboxes and
runs moves against Deep. Copy it to `mods/probe/title.lua` and edit the test
list (the `place(...); run(...)` lines). It selects DarthNox by `f.id == 61`;
use 63 for Mathilde.

## Engine facts that cost time (also in Claude's memory)

- **Frame movement:** a frame's `dvx` is re-applied, and its `dvy` is added,
  on **every tick of the frame**, including hit-lag ticks.
  - Launch on a frame without an itr, using an absolute dvy
    (`dvy > 500` sets the speed to `dvy - 550`).
  - End airborne moves with `next: 999`. Going to 212 re-runs the jump.
- **Landing:** touching the ground forces the crouch (219) unless the fighter
  is falling or burning. Use `physics.lua` to keep a move going.
- **Stun:** the stun counter steps 20/40/60 and doesn't decay during the
  3-tick hit lag. Multi-hit moves need `fall: 1` and `vrest` greater than the
  frame length plus 3.
- **Freezing:** hitting a frozen fighter shatters the ice into a knockdown.
- **Inherited hitboxes:** these are measured from the frame centre;
  `object_data.lua` rebases them. A frame becomes "ours" if it has a bdy or
  itr, or a name different from the base fighter's frame at that number;
  otherwise only its picture is swapped.
- **Sheet layout:** cells need a 1 px gutter. `row:` is the number of columns
  and `col:` the number of rows. Data files must be `.txt` (`.dat` gets
  decrypted). Any token in a data or bg file is limited to 29 characters.
- **Audio:** music must be WMA 8 (the only decoder is wmav2); sound effects
  can be any PCM WAV.
- **Homing:** a ball frame with `hit_Fa: 1` chases the nearest enemy.
- **Whirlwind:** itr kind 10/11 lifts people (Henry's flute, Freeze's
  whirlwind).
- **Effects:** itr `effect: 2` burns and `effect: 3` freezes.
- **Firen's ground fire:** spawn object 211 with action 50.
- **Burning fighters** damage anyone they touch, teammates included.
- **Credits:** never use AutoSprite `withSound` without asking.
